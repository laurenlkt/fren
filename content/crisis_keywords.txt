# Fren crisis keyword list
#
# HOW THIS FILE WORKS
# - Lines starting with # are comments and are ignored.
# - A line like [self-harm] starts a new CATEGORY. The category name is what
#   gets logged (never the participant's words, unless config allows it).
# - Every other line is a word or phrase. If a participant's message contains
#   it, Fren treats the message as a possible crisis.
# - Matching ignores capital letters, extra spaces and most punctuation.
#   Hyphens count as spaces, so "self harm" also matches "self-harm".
# - Phrases match whole words only: "die" would NOT match "diet".
#
# This list deliberately errs on the side of caution. A false alarm shows
# someone the help numbers; a missed crisis is far worse.
# Have this list reviewed by someone with safeguarding expertise.
